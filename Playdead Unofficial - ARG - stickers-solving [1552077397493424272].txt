**CE sticker symbols repeat every 108 stickers — here's where two independent analyses stopped, and what only you can supply**

Using the 82 stickers in stickers.md: symbols repeat with period 108, i.e. sticker N has the same mark as N+108, N+216, etc. Every position with two or more known stickers agrees (19 of 19 checks), 100,000 random shuffles never produce this, and all seven known dots fall in positions 85–98 even though their sticker numbers run 92–413 (roughly 1 in 150,000 by chance). Two separate analyses reproduced each other's numbers.

The cycle so far (? = unknown), 3 rows of 36:
```
?/--/?/?/-?-/-/?/--/-?--?-??//-/???/
-///?//-?///??-?-??/-?//??/?//??/---
?--/?////???./??..?.??./..??/??????/
```

What we could NOT get anywhere with: no readable message yet (Braille, binary vs LIFEDETECTED, overlay on the Cummings poem, and matching against every known printer string all come up empty or contradicted). No original copy of the dat/534brn9653f9j8mmd JPEG page exists in Wayback or archive.today — the surviving copy was saved as text and the bytes are gone. And 108-per-sheet is a standard label format, so this could be a print-sheet artifact rather than a puzzle. Those are honest limits, not a solve.

**Five things that would move this and that we can't do from a desk:**
1. The labeled 3×3 jigsaw of the background images (the old imgur link 846shEE is dead to us). Just the nine letters A–I in reading order is enough — that unlocks the one layout nobody has tested.
2. Stickers 197, 198, 200, 203, 205 are predicted to be DOTS. One clear photo of any of them either confirms or kills the model. #200 is the best test.
3. Unknown slots inside the dot region: 87, 88, 91, 93, 94 (or those +108, +216…).
4. Any CE owner: a photo of a sticker next to a ruler, and what the backing sheet looked like. That settles whether 108 is just the sheet size.
5. Did anyone save the terminal41 JPEG page in April 2020 as a raw file (not a browser "save as text")?

**Frequently Asked Questions**

**Q**: I think the symbols repeat every 108 stickers, has anyone noticed that?
**A**: Yes, we've known that for about 5 years. That part is already solved, we're 99.9% sure of it. We don't know why Oddheader said otherwise.

**Q**: Do you have the raw data of the known symbols of the 108-length string?
**A**: `/ /--/ / /- -/-/ /--/- -- -  //-/   /-/// //- ///  - -  /- //  / //  /--- --/ ////   ./  .. .  ./..  /      `

**Q**: What are those red-grey-yellow images that I keep seeing?
**A**: Red=`-` grey=`/` yellow=`.` and we often split the 108-length string into 12 rows for easier visualization.

**Q**: Why does the string start at sticker 0? Shouldn't it start at 1?
**A**: We're quite sure it has to start at sticker 0 (mod 108), because the other puzzle involving the sticker backgrounds started at sticker 0 (mod 9) in the top left corner, see https://discord.com/channels/460626942190813184/462637922944811028/704767641499205693

**Q**: Could it be just ordinary Morse? Because `. - /` look like Morse symbols.
**A**: Unlikely. So far there are no dots in the first 85 characters of the 108-length string. These 3 symbols are just the aesthetics of this ARG.

**Q**: This other cipher I found uses 3 different symbols, could it be that?
**A**: Unlikely. Unless it can explain the dots at the end, it's probably not a ternary (3-symbol) encoding, see https://discord.com/channels/460626942190813184/1552077397493424272/1554205291682463766
